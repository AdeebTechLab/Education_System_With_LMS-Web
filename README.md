# 📘 Education System With LMS (Web)

A Web-based **Education Management System** with integrated **Learning Management System (LMS)** capabilities — built using PHP, JavaScript, and common web technologies.

This project provides an online platform to manage students, faculty, classes, assessments, videos, and learning resources in a centralized system. 

---

## 🧠 About

This **Education System With LMS** is a full stack web application designed to help educational institutes deliver online learning alongside administrative tasks.  
Users — including **administrators**, **faculty**, and **students** — can log in, access course details, manage assessments, view results, send queries, and more. 

---

## 🚀 Features

✔️ User **authentication** for Admin, Faculty & Students  
✔️ Dashboard for role-based access (admin, faculty, student)  
✔️ Add and manage **students**, **faculty**, **assessments**, **videos**, and content  
✔️ Learning tools like **assessments**, **video lectures**, and **results**  
✔️ Public queries and student feedback forms  
✔️ Responsive web interface (HTML/CSS/JS + server-side logic)

## 👨‍🏫 How It Works

1. **Admin Panel**

   * Add/manage faculty, students, assessments, videos
   * Oversee results & queries

2. **Faculty Panel**

   * Create assessments
   * Upload videos and content
   * View student progress

3. **Student Panel**

   * Login to view content
   * Take tests and check results
   * Submit queries to admin/faculty
